Linux Commands
1. cat - view file without opening a text editor
2. diff - identifies  differences between two files, line by line
3. cksum - displays a file's filename, file size, and checksum; used for error detection
4. cp - copy files/directories to another location
5. rm - removes files or directories permanently; additional flags can be used, like -f which forces deletion and overrides write-protection, or -r which allows deletion of non-empty directories (flags can be combined)
6. touch - creates an empty file or updates an existing file
7. cd - changes the user's current working directory
8. rmdir - removes empty directories
9. chpasswd - changes the password for multiple users

GIT Commands
1. git status - displays modified and untracked files in current directory; can also display staged files from commits before pushing
2. git commit -m "message" - commits the staged changes with a message for logging purposes
3. git add - stages a specific changed file to prepare for the next commit; can be combined with the -all flag to stage every edited file
4. git checkout - switches to another branch as the working directory; can also be used for restoring files
5. git log - shows the reachable commit history for the current active branch
6. git fetch --all  - fetches from all the branches on the Git Remote while not modifying local branches; may be used to check for any new changes to the remote branches
7. git pull - fetches and merges changes from the remote repository's branch to update the local branch.
